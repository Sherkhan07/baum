# BaumGuard — Баум тоғайында өртті ерте анықтау жүйесі

Алматы қаласындағы Баум тоғайына (Түрксіб ауданы, 137,7 га) арналған оқушының ғылыми жобасы.

**Ғылыми жетекшісі:** Ауылбай Нұржан, Шоқан Уалиханов атындағы №12 мамандандырылған лицей, Алматы.

## Файлдар

| Файл | Сипаттамасы |
|---|---|
| `BaumGuard 3D (жаңа нұсқа).html` | Негізгі веб-прототип: нақты карта, 3D модель, датчиктер, өрт таралу моделі, өрт сөндіру бөлімдерінің маршруттары, іс-қимыл жоспары, виртуалды бақылау дроны |
| `BaumGuard ғылыми жоба.docx` | Ғылыми жобаның мәтіні (Word) |
| `BaumGuard (2) жаңа Нұсқа.html` | Прототиптің алғашқы нұсқасы |
| `Қазақстан ормандары.html` | «Баум тоғайынан Қазақстан ормандарына» бөлімі: жер бедері бар 3D Қазақстан картасы, Баум тоғайы / Іле Алатауы / «Семей орманы» / Бурабай аумақтарының 3D модельдері (ағаштар, жер бедері, өзендер, D1–D5 датчиктері, ретранслятор), виртуалды датчиктер, түтін және 3D дрон сценарийі (дрон камерасынан «Үлгі бейне»), салыстыру кестесі, сынақ жоспары, журнал, дереккөздер. Баум, Семей (Қарағайлы), Бурабай және Тараз сахналары OpenStreetMap деректерінен (нақты үйлер, көшелер мен аттары, орман, су) және нақты биіктіктен (SRTM) құрылған, 🛰 батырмасы спутник суретін салады (интернет қажет); Тараздағы Айша бибі мен Бабаджа қатын кесенелерінің 3D моделі; нақты ауа райы (Open-Meteo) және Нестеров өрт қаупі индексі; жел, жер бедері мен отын бойынша өрттің таралу моделі (үйлерге жету уақыты, өртенген гектар); ең жақын өрт сөндіру бөлімінің нақты маршруты (OSRM) және 3D-дегі өрт сөндіру көлігі; дрон камерасындағы тепловизор режимі; әр аумақтың нақты картадағы орны (OpenStreetMap / Esri спутник, интернет қажет). Аумаққа тікелей сілтеме (QR-код үшін): `#baum`, `#ile`, `#semey`, `#burabay`, `#taraz` |
| `index.html` | Негізгі прототипке бағыттайтын бет |
| `drone-icon.svg` | Виртуалды бақылау дронының белгісі (сайт пен pop-up макет үшін) |

## Қалай ашу керек

HTML файлын кез келген заманауи браузерде (Chrome, Edge, Safari) ашыңыз — интернет қажет емес, барлық деректер файлдың ішінде.
