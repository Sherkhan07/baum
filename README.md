# BaumGuard — Баум тоғайында өртті ерте анықтау жүйесі

Алматы қаласындағы Баум тоғайына (Түрксіб ауданы, 137,7 га) арналған оқушының ғылыми жобасы.

**Ғылыми жетекшісі:** Ауылбай Нұржан, Шоқан Уалиханов атындағы №12 мамандандырылған лицей, Алматы.

## Файлдар

| Файл | Сипаттамасы |
|---|---|
| `BaumGuard 3D (жаңа нұсқа).html` | Негізгі веб-прототип: нақты карта, 3D модель, датчиктер, өрт таралу моделі, өрт сөндіру бөлімдерінің маршруттары, іс-қимыл жоспары, виртуалды бақылау дроны |
| `BaumGuard ғылыми жоба.docx` | Ғылыми жобаның мәтіні (Word) |
| `BaumGuard (2) жаңа Нұсқа.html` | Прототиптің алғашқы нұсқасы |
| `index.html` | Негізгі прототипке бағыттайтын бет |
| `drone-icon.svg` | Виртуалды бақылау дронының белгісі (сайт пен pop-up макет үшін) |

## Қалай ашу керек

HTML файлын кез келген заманауи браузерде (Chrome, Edge, Safari) ашыңыз — интернет қажет емес, барлық деректер файлдың ішінде.
